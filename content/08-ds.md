# method | Data Science Methodology
N: **IBM's Data Science Methodology (John Rollins) — 10 stages**: 1 **Business Understanding** → 2 **Analytic Approach** → 3 **Data Requirements** → 4 **Data Collection** → 5 **Data Understanding** → 6 **Data Preparation** → 7 **Modeling** → 8 **Evaluation** → 9 **Deployment** → 10 **Feedback**. It is **iterative** (feedback loops back).
N: Guiding questions: Business understanding — "What is the problem you are trying to solve?"; Analytic approach — "How can you use data to answer the question?"; Data requirements — "What data do you need?"; Data collection — "Where is the data coming from and how will you get it?"; Data understanding — "Is the data representative of the problem?"; Data preparation — "What additional work is needed to manipulate the data?"; Modeling — "How can the data be visualised/modelled to get the answer?"; Evaluation — "Does the model answer the initial question?"; Deployment — "Can you put the model into practice?"; Feedback — "Can you get constructive feedback?"
N: **Data preparation** (cleaning, missing values, feature engineering) is usually the **most time-consuming** stage (often 70–80% of the effort).
N: Analytic approach types: **descriptive** (what is happening), **diagnostic** (why), **predictive** (what will happen), **prescriptive** (what should we do); classification for yes/no outcomes.
N: **CRISP-DM** (6 phases): Business understanding → Data understanding → Data preparation → Modeling → Evaluation → Deployment.

# linregds | Linear Regression for Business Analytics
N: Regression predicts a **continuous** target (sales, price, demand). Simple: y = b₀ + b₁x; multiple: y = b₀ + Σbᵢxᵢ. Coefficients are found by **ordinary least squares** (minimise SSE).
N: **Interpretation**: b₁ = change in y per 1-unit increase in x (holding the others constant in multiple regression). b₀ = predicted y when all x = 0.
N: Fit quality: **R²**, adjusted R², RMSE; check **residual plots** (random scatter = good; patterns = misspecification), and use p-values for coefficient significance.
N: Python: `np.polyfit(x, y, 1)` returns [slope, intercept]; scikit-learn `LinearRegression().fit(X, y)` → `.coef_`, `.intercept_`, `.predict()`, `.score()` (R²). statsmodels OLS gives full summaries.
N: Normal equation: **b = (XᵀX)⁻¹Xᵀy**. Train/test split to check generalisation. Dummy (one-hot) variables encode categories.

# linopt | Linear Optimization (Linear Programming)
N: **LP**: optimise (max/min) a **linear objective** subject to **linear constraints** and non-negativity. Components: **decision variables**, **objective function**, **constraints**.
N: **Feasible region** = all points satisfying the constraints (a convex polygon in 2-D). **Corner-point theorem**: if an optimum exists, it occurs at a **vertex (corner point)** of the feasible region.
N: Graphical method (2 variables): plot the constraints, find the corners, evaluate the objective at each corner. Simplex method moves from vertex to vertex (for many variables).
N: Special cases: **infeasible** (no point satisfies all constraints), **unbounded** (objective can improve forever), **multiple optima** (objective parallel to a binding constraint).
N: **Slack** = unused amount of a ≤ constraint. **Binding constraint** = slack 0 at the optimum. **Shadow price (dual value)** = change in the optimal objective per one-unit increase in a constraint's RHS.
N: Python: **`scipy.optimize.linprog`** **minimises** by default → to maximise, minimise −c. Also PuLP. Applications: product mix, diet problem, transportation, scheduling, portfolio.

Q: In linear programming, the optimal solution (if it exists) always lies:
* At a corner point (vertex) of the feasible region ~~ Corner-point theorem.
- At the centre of the feasible region ~~ No.
- Outside the feasible region ~~ Must be feasible.
- On the x-axis only ~~ Not necessarily.
H: Check the corners.

Q: Maximise Z = 3x + 2y subject to x + y ≤ 4, x + 3y ≤ 6, x, y ≥ 0. The maximum Z is:
- 11 ~~ That's at (3, 1).
* 12 ~~ Corners: (0,0) → 0, (4,0) → 12, (3,1) → 11, (0,2) → 4.
- 4 ~~ At (0, 2).
- 10 ~~ No.
H: Evaluate Z at every corner.

Q: Maximise Z = 5x + 4y subject to 6x + 4y ≤ 24, x + 2y ≤ 6, x, y ≥ 0. The optimal solution is:
- x = 4, y = 0, Z = 20 ~~ A corner, but not the best.
* x = 3, y = 1.5, Z = 21 ~~ The intersection of both constraints gives the highest Z.
- x = 0, y = 3, Z = 12 ~~ Lower.
- x = 6, y = 0, Z = 30 ~~ Violates 6x + 4y ≤ 24.
H: Solve the binding constraints together.

# numpy | Linear Algebra with NumPy
N: `np.array([[1,2],[3,4]])` → 2-D array; `.shape` (rows, cols), `.ndim`, `.size`, `.dtype`. `np.zeros`, `np.ones`, `np.eye(n)` (identity), `np.arange`, `np.linspace`, `.reshape`.
N: `*` is **element-wise** multiplication; **matrix multiplication** uses `np.dot(A, B)`, `A @ B` or `np.matmul`. Inner dimensions must match: (m×n)·(n×p) → (m×p).
N: `A.T` transpose; `np.linalg.inv(A)` inverse; `np.linalg.det(A)` determinant; **`np.linalg.solve(A, b)`** solves Ax = b; `np.linalg.eig(A)` eigenvalues/vectors; `np.linalg.norm(v)` length; `np.linalg.matrix_rank(A)`.
N: For A = [[1,2],[3,4]]: det = −2; inv = [[−2, 1], [1.5, −0.5]]; A@A = [[7,10],[15,22]]; A*A = [[1,4],[9,16]].
N: **Broadcasting**: shapes are compared from the right; dimensions match if equal or 1 → (3,1) + (1,4) → (3,4).
N: `axis=0` operates down the rows (column-wise result); `axis=1` across columns (row-wise result). A singular matrix (det = 0) has no inverse.

# prob | Continuous & Discrete Probability Distributions
N: **Discrete** (countable values, **PMF**): **Bernoulli** (one trial, p), **Binomial**(n, p) — mean **np**, variance **np(1 − p)**; **Poisson**(λ) — counts per interval, **mean = variance = λ**; **Geometric** — trials until the first success, mean 1/p; discrete uniform.
N: **Continuous** (**PDF**; P(X = exact value) = 0; probabilities are areas): **Uniform**[a, b] — mean (a + b)/2, variance (b − a)²/12; **Normal**(μ, σ) — symmetric bell; **Exponential**(λ) — time between events, mean 1/λ, **memoryless**; also t, chi-square, log-normal.
N: **Empirical rule** (normal): ~**68%** within 1σ, **95%** within 2σ, **99.7%** within 3σ. **z-score** = (x − μ)/σ; the standard normal has μ = 0, σ = 1.
N: **CDF** F(x) = P(X ≤ x). Expected value E[X] = Σx·p(x) (discrete) or ∫x·f(x)dx (continuous).
N: Python: `scipy.stats` (binom, poisson, norm, expon, uniform: .pmf/.pdf/.cdf), `np.random.normal/binomial/poisson`.
N: **Central Limit Theorem**: means of large samples are approximately normal, whatever the population's shape.

# eda | Exploratory Data Analysis
N: **EDA** (John Tukey): explore data **before modelling** using summary statistics and visualisations to understand distributions, spot **outliers, missing values, errors**, relationships and patterns, and form hypotheses.
N: Steps: inspect structure (`shape`, `info`, `dtypes`, `head`), summary stats (`describe`), missing values (`isnull().sum()`), duplicates, univariate analysis (histograms, box plots), bivariate (scatter, correlation `df.corr()`, heatmaps), multivariate (pairplots).
N: **Central tendency**: mean (sensitive to outliers), median (robust), mode. **Spread**: range, variance, standard deviation, **IQR = Q3 − Q1**.
N: **Outliers by the IQR rule**: below **Q1 − 1.5·IQR** or above **Q3 + 1.5·IQR**. Also z-score > 3.
N: **Skewness**: right (positive) skew → long right tail, **mean > median**; left (negative) skew → mean < median; symmetric → mean ≈ median.
N: **Correlation ≠ causation**. Pearson r measures linear association; Spearman measures monotonic (rank) association.

- Replace statistical modelling ~~ It informs modelling.
H: EDA = get to know your data first.

H: EDA & box plot → Tukey.
