# switching | Switching: Circuit, Packet, Frame Relay, Cell & ATM
N: **Circuit switching**: a dedicated path is set up first (setup → transfer → teardown); **connection-oriented**; works at the **physical layer**; good for **constant-rate, long-duration** traffic (telephone).
N: **Packet switching** (network layer): **store-and-forward**; **datagram** = connectionless (each packet routed independently, may arrive out of order); **virtual circuit** = connection-oriented (all packets follow the same route; uses **global and local (VCI) addressing**). If a VC router fails, all virtual circuits through it are terminated.
N: A switched network consists of interlinked nodes called **switches**. A crossbar switch with n inputs and m outputs needs **n × m crosspoints** (30 × 30 = 900).
N: **Frame Relay**: virtual-circuit WAN technology at the data-link level; **no error or flow control** (left to higher layers); uses DLCI identifiers; designed for bursty data.
N: **Cell switching / ATM**: fixed-size **53-byte cells (5-byte header + 48-byte payload)**; connection-oriented virtual circuits identified by **VPI/VCI**. Fixed cells → predictable delay, good for voice + video + data.
N: **ATM adaptation layers**: AAL1 (constant bit rate), AAL2 (variable-bit-rate audio/video), **AAL3/4 (data: AAL3 connection-oriented, AAL4 connectionless)**, AAL5 (simple, efficient data — SEAL).
N: **Bursty data**: the data rate changes suddenly in a very short time.

# models | OSI & TCP/IP Models
N: **OSI (7)**: Physical, Data link, Network, Transport, Session, Presentation, Application ("**P**lease **D**o **N**ot **T**hrow **S**ausage **P**izza **A**way").
N: **TCP/IP model** (4/5 layers): Network access/Link, Internet, Transport, Application — **no separate Session or Presentation layer**.
N: **Physical**: bits, signals, **data rate/transmission speed**. **Data link**: framing, MAC, **flow and error control (hop-to-hop)**. **Network**: logical addressing, **routing, internetworking** (error control is not its main job). **Transport**: process-to-process delivery, ports, **multiplexing/aggregating data from processes** and passing it to the network layer, end-to-end flow/error control. **Session**: dialog control, synchronisation. **Presentation**: **encryption/decryption**, compression, translation. **Application**: user services.
N: PDUs: bits (physical), **frames** (data link), **packets/datagrams** (network), **segments** (TCP) / user datagrams (UDP), messages (application).
N: **IPv4 header = 20 bytes + up to 40 bytes of options** (20 + 20 options = 40 bytes).
N: Devices by layer: hub/repeater (L1), switch/bridge (L2), router (L3), gateway (all layers / protocol conversion).

# topology | Topologies, Devices, LANs & Signals
N: **Mesh**: n devices → **n(n − 1)/2 links**, each device needs **n − 1 ports**; **highest reliability, redundant links**, but expensive and hard to install. **Star**: each device connected individually to a **central hub/switch** (hub failure = single point of failure). **Bus**: one backbone (classic **Ethernet**). **Ring**: each device connects to two neighbours.
N: **Hub** (L1): repeats/broadcasts to all ports. **Switch** (L2): forwards frames only to the destination port using MAC tables. **Router** (L3): connects **different networks**, builds routing tables, forwards packets. **Gateway**: connects networks with **different protocols**.
N: **LAN**: covers a few km (building/campus), high speed (classic Ethernet up to 1000 Mbps). **MAN**: city. **WAN**: country/global — the **Internet is a WAN**.
N: Transmission modes: **simplex** (one way: keyboard), **half duplex** (both ways, one at a time: **walkie-talkie**), **full duplex** (both at once: telephone).
N: **MAC address** = 48 bits, written as 6 hex pairs (07:01:02:01:2C:4B). **IPv4** = **32 bits**; IPv6 = 128 bits.
N: Signals: **analog** = infinite values in a range; digital = limited values. Both can be **periodic or non-periodic**. One full pattern = **cycle**; time for a cycle = period (T = 1/f). **Bandwidth** = highest − lowest frequency.
N: **Nyquist** (noiseless): max bit rate = **2B log₂L**. **Shannon** (noisy): C = **B log₂(1 + SNR)**.
N: Cast types: unicast (one-to-one), multicast (one-to-many), **broadcast (one-to-all)**.

# errors | Error Detection & Correction
N: **Single-bit error**: exactly 1 bit changed (10100101 → 10100100). **Burst error**: **2 or more bits** changed.
N: **Hamming distance** = number of differing bits (XOR and count the 1s). To **detect s errors** dmin = s + 1; to **correct t errors** dmin = 2t + 1.
N: **Simple parity** detects **any odd number** of errors, not even numbers. 2-D parity detects more.
N: **CRC**: append (degree) zeros, divide by the generator using **modulo-2 (XOR)** arithmetic; the remainder is the CRC. In modulo-2, 1 + 1 = 0.
N: **Checksum** (Internet): **1's complement** arithmetic; the sender sends the complement of the sum; the receiver's sum + checksum = all 1s.
N: **Hamming code**: r parity bits for m data bits with **2^r ≥ m + r + 1** (4 data → 3 parity: Hamming(7,4)). The syndrome gives the **position of the error bit**.

# routing | Routing Algorithms & Protocols
N: **Static routing**: routes **manually configured** by an administrator. **Dynamic routing**: routes learned via protocols and updated automatically.
N: **Distance vector** (Bellman–Ford): share the whole table with **neighbours** periodically; slow convergence, **count-to-infinity** problem. Example: **RIP** (intradomain, hop count, max 15 hops).
N: **Link state** (Dijkstra): flood link-state info to **all** routers; each computes the shortest paths. Example: **OSPF** (intradomain; cost can be based on bandwidth/throughput).
N: **Path vector**: used **between autonomous systems** (interdomain). Example: **BGP**.
N: **Intradomain** (inside an AS): RIP, OSPF. **Interdomain** (between ASes): BGP.
N: Count-to-infinity fixes: split horizon, poison reverse, hold-down timers.

# congestion | Flow Control & Congestion Control
N: **Flow control** protects the **receiver** (don't overwhelm it). **Congestion control** protects the **network**.
N: **Open-loop (prevention)** policies: retransmission, window, acknowledgment, **discarding policy** (routers discard less-sensitive packets to prevent congestion without harming the integrity of the transmission, e.g. in audio), admission policy.
N: **Closed-loop (removal)**: **Back pressure** (node-to-node: a congested node stops receiving from its upstream node), **choke packet** (sent from the congested router directly to the source), implicit signalling, explicit signalling (forward/backward — Frame Relay FECN/BECN).
N: **TCP congestion control**: **slow start** (cwnd doubles each RTT, exponential) until ssthresh → **congestion avoidance** (additive increase, +1 MSS per RTT). On timeout: ssthresh = cwnd/2, cwnd = 1 MSS. On 3 duplicate ACKs (fast recovery): cwnd = ssthresh. This is **AIMD**.
N: Traffic shaping: **leaky bucket** (smooth constant output rate) and **token bucket** (allows bursts up to the bucket size).

# crypto | Cryptosystems: Symmetric & Public Key
N: **Symmetric (private/secret-key)**: **same key** to encrypt and decrypt; **fast**; key distribution is hard. Examples: **DES** (56-bit key, 64-bit block, 16 rounds), 3DES, **AES** (128-bit block; 128/192/256-bit keys with **10/12/14 rounds**), RC4, Blowfish. **S-AES** (simplified AES, teaching): 16-bit key, 16-bit block.
N: **Asymmetric (public-key)**: **public key encrypts, private key decrypts**; the private key is kept secret. Used for encryption, **authentication/digital signatures**, and **key exchange**. Slower, but **simpler key management** (n users need n key pairs instead of n(n−1)/2 secret keys). Examples: **RSA**, Diffie–Hellman, ECC, ElGamal.
N: **RSA**: n = p·q, φ = (p−1)(q−1), choose e coprime to φ, d = e⁻¹ mod φ. Encrypt C = Mᵉ mod n; decrypt M = Cᵈ mod n. (p = 3, q = 11 → n = 33, φ = 20, e = 7 → d = 3.)
N: **Diffie–Hellman** key exchange: public prime q and generator α; A sends α^a mod q, B sends α^b mod q; shared key = α^(ab) mod q. Vulnerable to man-in-the-middle without authentication.
N: **Caesar cipher**: shift letters by 3 (decrypt by shifting back 3: HQFUBSWHG → ENCRYPTED).
N: **Hash functions** (SHA, MD5): one-way, fixed-length digest — used for integrity, **not encryption**.
N: **Attacks**: brute force (try all keys/passwords), dictionary (common words), **rainbow table (pre-computed hashes)**, social engineering (trick people), **man-in-the-middle** (intercept and modify).

# dsig | Digital Signatures & Key Management
N: **Digital signature**: the sender **signs with its own PRIVATE key** (usually the hash of the message); the receiver **verifies with the sender's PUBLIC key**. Needs a **public-key system** (RSA, DSA).
N: Provides **authentication, integrity and non-repudiation** — **not confidentiality** (if confidentiality is needed, apply encryption on top).
N: Conventional signature is **included in** the document (one-to-many); a digital signature is a **separate entity** with a **one-to-one** relationship to the document.
N: **MAC** (keyed hash) authenticates the **data origin** and integrity. **MDC** (plain hash) only detects modification.
N: **Birthday attack** on signatures: the **signer S** can prepare two messages with the same hash and later claim the fraudulent one.
N: **Public-key distribution**: public announcement (least secure), publicly available directory, **public-key authority** (a trusted third party distributes keys on request), **public-key certificates** (most secure, signed by a CA — X.509). With a key authority, 7 messages are needed but the first 5 are rarely repeated thanks to **caching**.
N: **X.509 certificates**: v1 basic; **v2 added issuer and subject unique identifiers**; v3 added extensions.
N: **KDC** (key distribution centre) issues a **session key** for each communication session (**used only once** — for that session). Secret-key distribution with a KDC needs n keys (one per member).
