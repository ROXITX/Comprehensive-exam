# linreg
S: 📈 Linear regression — draw the best line
> Predict a **number** (price, temperature) from inputs by fitting a straight line:
> **Y = b₀ + b₁X**
> - b₁ (slope) = how much Y changes when X goes up by 1
> - b₀ (intercept) = Y when X = 0
> 💡 Y = 55.1 + 0.28X → each extra unit of X adds 0.28 to Y.
S: Which line is "best"?
> The one with the **smallest sum of squared errors** (residual = actual − predicted). This is **least squares**.
> Multiple regression just adds more X's: Y = b₀ + b₁X₁ + b₂X₂ + …
S: How good is the line? R²
> **R² = 1 − SSE/SST** = the share of the variation explained (0 to 1).
> SST = 400, SSE = 75 → R² ≈ **0.81**.
> Use R², MSE, RMSE for regression (precision/recall are for classification).
S: Assumptions about the errors
> Errors should have **mean 0**, constant spread, be independent, and be roughly normal.
> - Correlation r is between −1 and +1 (strong negative ≈ −1).
> - Swapping X and Y keeps r and R² but changes the SSE.

# logreg
S: 🔢 Logistic regression = yes/no prediction
> Used for **classification** (pass/fail, fire/no fire).
> It squeezes a line through the **sigmoid** σ(z) = 1/(1 + e⁻ᶻ) → a probability between 0 and 1.
> σ(0) = 0.5 → the usual decision line.
S: Odds
> **Odds = P / (1 − P)** — chance it happens ÷ chance it doesn't.
> P = 0.75 → odds = **3**.
> The log of the odds is a straight line in the inputs; e^coefficient = odds ratio.
S: Training & judging it
> Trained by minimising **log loss (cross-entropy)**.
> - Precision = TP/(TP + FP)
> - Recall = TP/(TP + FN)
> - Many classes → **softmax**

# linnon
S: ➖ Linear vs non-linear
> **Linearly separable**: one straight line can split the classes.
> **XOR** can't be split by one line → needs a non-linear model.
S: SVM — the widest street
> An SVM finds the line (hyperplane) with the **biggest margin** between classes.
> The closest points are the **support vectors**. Margin = 2/‖w‖.
> Points x = 1 (+) and x = −1 (−) → w = 1, b = 0 (boundary at 0).
S: The kernel trick
> Instead of drawing curves, the kernel lifts the data into a higher dimension where a straight line works — without computing that dimension.
> - Linear: x·y
> - **Polynomial**: (x·y + c)ᵈ
> - **RBF/Gaussian**: exp(−γ‖x − y‖²) (big γ → overfits)
> Valid kernels satisfy **Mercer's condition**.

# knn
S: 👥 k-Nearest Neighbours
> To classify a new point, look at its **k closest** training points and take a **majority vote**.
> 💡 "Tell me who your neighbours are and I'll tell you who you are."
S: Key facts
> - **Lazy**: no training step — it just stores the data.
> - **Non-parametric**: no assumptions about the data.
> - Works for classification **and** regression (and filling missing values).
S: Choosing k and distance
> - Small k → **high variance**, low bias (noisy)
> - Large k → smoother, higher bias → use a **bigger k for noisy data**
> - Distances: Euclidean, **Manhattan** (|5−1| + |4−1| = 7), **Hamming** for categorical data
> - Scale your features first!

# kmeans
S: 🎯 k-Means clustering
> Group unlabelled data into **k clusters**:
> 1. Pick k centres
> 2. Assign each point to its **nearest centre**
> 3. Move each centre to the **mean** of its points
> 4. Repeat until nothing changes
S: Worked example
> Data {2, 6, 10, 14, 18, 7}, centres 4 and 12:
> - {2, 6, 7} → mean **5**
> - {10, 14, 18} → mean **14**
S: Strengths & weaknesses
> - Choose k with the **Elbow method**
> - ❌ Sensitive to **outliers** and starting points; only round (convex) clusters
> - Categorical data → **k-modes**; robust version → k-medoids
S: Other clustering
> - **Hierarchical**: merge the closest clusters step by step (single linkage = closest pair; complete = farthest pair)
> - **DBSCAN**: density-based, any shape, marks noise

# som
S: 🗺️ Self-Organizing Map (Kohonen)
> An **unsupervised neural network** that places high-dimensional data on a **2-D grid**, keeping similar items close together.
> 💡 Like arranging books on a shelf so similar topics sit next to each other.
S: How it learns
> 1. Start with **random weights** for each grid node
> 2. For each input, find the **Best Matching Unit** (closest node)
> 3. Pull the BMU **and its neighbours** toward the input
> 4. Shrink the neighbourhood and learning rate over time
> This is **competitive learning** — no backpropagation, no labels.

# rf
S: 🌲 Decision trees
> Ask yes/no questions about features to split the data into pure groups.
> - Impurity: **entropy** (50/50 → 1) or **Gini** (50/50 → 0.5)
> - Choose the split with the best **information gain**
> Trees overfit easily.
S: Bagging & Random Forest
> **Bagging**: train many models on **random samples with replacement**, then vote → lowers **variance**.
> **Random Forest** = bagged trees + a **random subset of features** at each split.
S: Boosting (AdaBoost)
> Train models **one after another**; each focuses on the previous mistakes → lowers **bias**.
> - Points **misclassified by the last model** get more weight.
> - Model weight α = ½ ln((1 − ε)/ε); worse than 50% → negative α → thrown away.

# nb
S: 🎲 Naive Bayes
> Uses **Bayes' theorem** to pick the most likely class:
> P(class | data) ∝ P(data | class) × P(class)
> "Naive" = it assumes the features are **independent given the class**.
S: Counting parameters
> n yes/no features + a yes/no label → **2n + 1** numbers to learn.
> 4 inputs → **9**.
> Even with perfect data it can still make some errors (classes can overlap).
S: Where it shines
> Fast, needs little data, great for **text/spam** (Multinomial NB).
> **Laplace smoothing** avoids zero probabilities.

# semi
S: 🌗 Semi-supervised learning
> Labels are expensive, raw data is cheap. Use a **few labelled** examples + **lots of unlabelled** ones.
S: Common methods
> - **Self-training**: label the points you're confident about, then retrain
> - **Co-training**: two models with different views teach each other
> - **Label propagation**: spread labels through a similarity graph
> Assumption: points in the same cluster share a label.
S: EM algorithm
> For hidden (latent) variables:
> - **E-step**: estimate the hidden values
> - **M-step**: update the parameters
> To get MAP estimates instead, change only the **M-step** (add the prior).

# unsupnn
S: 🧠 Neural networks without labels
> - **Autoencoder**: squeeze the input into a small code, then rebuild it. Learns features with no labels.
> - **RBM** (trained by contrastive divergence); stacked RBMs → Deep Belief Network.
> - **Hebbian learning**: "fire together, wire together".
> - **GAN**: a generator vs a discriminator.
S: Backprop facts
> Gradients through sigmoid/tanh **never change sign** (their slopes are positive) but they shrink → **vanishing gradients** (sigmoid slope ≤ 0.25).
> **ReLU** helps deep networks train.

# cnn
S: 🖼️ CNNs — networks for images
> Small **filters** slide over the image to detect edges, shapes, then objects.
> Shared weights → far fewer parameters than fully connected layers.
> Layers: convolution → ReLU → pooling → … → fully connected → softmax.
S: Size & parameter formulas
> - Output size = **(W − F + 2P)/S + 1** (32, 5×5 filter, no padding → 28)
> - Parameters = (F × F × channels + 1) × filters
> - 2×2 max-pool with stride 2 **halves** width and height.
S: Famous architectures
> - **LeNet-5** (1998): digits
> - **AlexNet** (2012): ReLU, dropout, GPUs
> - **VGG**: only 3×3 filters, very deep
> - **GoogLeNet/Inception**: parallel 1×1, 3×3, 5×5 filters
> - **ResNet**: **skip connections** (add the input back) → 100+ layers

# rcnn
S: 📦 Object detection
> Find **what** objects are in an image **and where** (bounding boxes).
> Measured with **IoU** = overlap ÷ union (two 100-area boxes overlapping by 50 → 0.33).
S: The R-CNN family (two-stage)
> - **R-CNN**: selective search → ~2000 regions → CNN on each → SVMs. Accurate but **slow**.
> - **Fast R-CNN**: run the CNN **once**, then **RoI pooling** per region.
> - **Faster R-CNN**: a **Region Proposal Network** with **anchor boxes** replaces selective search.
> - **Mask R-CNN**: adds pixel masks (**RoIAlign**).
> **NMS** removes duplicate boxes.

# yolo
S: ⚡ YOLO — You Only Look Once
> Detection in **one pass** of one network → **real-time** (~45 fps). A **one-stage** detector.
S: How YOLO v1 works
> - Split the image into a **7 × 7 grid**
> - Each cell predicts **2 boxes** (x, y, w, h, confidence) + **20 class** scores
> - Output = 7 × 7 × **30**
> - The cell holding an object's **centre** is responsible for it
S: Strengths & limits
> ✅ Very fast, sees the whole image.
> ❌ Struggles with **small objects in groups**.
> v2 added anchor boxes; v3 predicts at **3 scales**.

# densenet
S: 🔗 DenseNet
> Inside a **dense block**, every layer gets the outputs of **all earlier layers**, joined by **concatenation**.
> 💡 ResNet **adds** the shortcut; DenseNet **concatenates** everything.
S: Numbers to know
> - L layers → **L(L + 1)/2** connections (5 layers → 15)
> - **Growth rate k** = new channels each layer adds
> - Output channels = k₀ + L·k (64 + 6 × 32 = 256)
> - **Transition layers**: 1×1 conv + 2×2 average pooling
S: Why it's good
> Feature reuse, strong gradient flow (less vanishing), **fewer parameters**.

# dqn
S: 🎮 Reinforcement learning
> An **agent** takes **actions**, gets **rewards**, and learns a **policy** that maximises future reward.
> Discount γ: rewards later count less (γ near 0 → short-sighted).
S: Q-learning
> **Q(s, a)** = how good action a is in state s.
> Update: Q ← Q + α [r + γ·max Q(next) − Q]
> Q = 0, α = 0.5, r = 10, γ = 0.9, max Q(next) = 20 → **14**.
> Q-learning finds the **optimal policy** (off-policy).
S: Deep Q-Network (DQN)
> A CNN **approximates Q** from raw game pixels (Atari).
> - **Experience replay**: learn from random old experiences
> - **Target network**: a frozen copy keeps targets stable
> - **ε-greedy**: sometimes explore randomly
> Double DQN reduces overestimation; Dueling DQN splits V and A.
